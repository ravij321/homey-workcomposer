# Homey Work Insights

A privacy-first work activity and productivity insights platform for Homey.

## Goals

- Track work activity without screenshots.
- Integrate endpoint/MDM data such as Scalefusion through a secure backend.
- Provide useful dashboards for admins and managers.
- Support device, user, application, event, and department-level insights.
- Maintain audit-friendly records and role-based administration.

## MVP architecture

- `client/` — web dashboard
- `server/` — API and integrations
- `docs/` — product and security documentation

## Privacy principles

The product is designed around activity metadata rather than screenshots or invasive content capture. Data collection should be limited to what is necessary for legitimate workplace administration and reporting.

## Initial dashboard

The new version should provide:

1. Overview KPIs
2. Work activity trends
3. Device inventory
4. User and department insights
5. Application/activity breakdown
6. MDM health and compliance
7. Admin management and invitations
8. Audit log
